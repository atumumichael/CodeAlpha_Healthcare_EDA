# Health Care Data Analysis

## Project Overview
This project analyses hospital patient data using Microsoft Power BI to identify patterns in patient demographics, medical conditions, hospital admissions, billing amounts, and length of hospital stay.

The dashboard provides an interactive view of healthcare data to support exploratory analysis and data-driven decision-making.

## Tools Used
- Microsoft Power BI
- Python (Pandas)
- Google Colab

## Dataset
Source: [Healthcare Dataset – Kaggle](https://www.kaggle.com/datasets/prasad22/healthcare-dataset)

- Original records: 55,500
- Records after removing duplicates: 54,966
- Missing values: None identified
- Dataset type: Public healthcare dataset

## Dashboard Features

### Key Performance Indicators (KPIs)
- Total Patients
- Average Age
- Average Length of Stay
- Total Billing Amount
- Abnormal Test Results

### Visualisations
1. Patient Distribution by Medical Condition
2. Patient Distribution by Age Group
3. Patient Distribution by Admission Type
4. Average Billing Amount by Medical Condition
5. Average Length of Stay by Admission Type
6. Patient Distribution by Test Results
7. Average Billing Amount by Age Group

### Interactive Filters
- Gender
- Medical Condition
- Admission Type

## Key Findings
- The dataset contains 54,966 patient records after duplicate removal.
- Average patient age is approximately 51.54 years.
- Average hospital stay is approximately 15.50 days.
- Abnormal test results account for 18,437 records.
- Elective, emergency, and urgent admissions have similar patient volumes.

## Project Objective
To develop practical skills in healthcare data analysis, data visualisation, dashboard development, and communicating analytical findings.

## Limitations
- The dataset does not establish clinical relationships or causation.
- The billing currency is unspecified.
- The dataset should not be assumed to represent all real-world hospital populations.

## Conclusion
The project demonstrates how Power BI can transform healthcare datasets into interactive dashboards that make patient distributions, admission patterns, and billing information easier to explore.
